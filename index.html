为什么需要这一层

直接把一句话丢给执行型 agent

  • 工人不知道要交出什么、怎么算做完，于是自己猜
  • 猜错了你还得重来一遍，返工比第一次做还贵
  • 工人说"我做完了"，你就得自己逐条核对

把这两件事变成机器的职责

  • 施工单派出去之前先体检 + 改写，达标才发车
  • 交活之后由老板逐条对照验收标准判定
  • 不通过就产出返工说明，自动重做一轮

提示词优化器

分三级，先便宜后贵，从不无脑烧 token。

第一级 · 规则体检

零成本、毫秒级，七个维度打分。这一级永远先跑。

第二级 · 模型改写

分数低于达标线才叫模型改写；改完重新体检，分数没涨就丢弃，最多两轮。

第三级 · 学习闭环

第一次就通过验收的施工单会存进 library.jsonl，之后改写会参考它们。

老板顺手挑出的毛病

它的验收笔记里主动指出"验收基于工人书面声明，建议抽查文件源码"，还发现了评分函数里一个真实计分 bug：二元维度缺失时仍给满分。

那个 bug 已修；工人写的测试断言的是性质而非写死的分数，修复后 16 个测试依然全过。

托管方案

这个站是纯静态、零依赖的，放哪家都能托管。按你的取舍选：

方案适合成本国内访问自动部署备案
Cloudflare Pages静态站首选免费一般Git 推送即部署不需要
GitHub Pages已有仓库免费一般附带的 workflow 直接可用不需要
Vercel静态站 / 前端免费额度一般Git 推送即部署不需要
阿里云 OSS + CDN国内速度优先几元/月起好需自接 CI绑域名需备案
腾讯云轻量 + Coolify还要跑控制台 / 后端约 50 元/月起好面板一键部署绑域名需备案

纯静态站在中国大陆用域名提供 HTTP 服务需要 ICP 备案；只按 IP 访问可以绕开，但没法用 HTTPS 域名。 如果你以后要的是"在浏览器里点按钮派活、看运行记录"的控制台，那就得有一台常驻服务器来跑 BossFlow， 这时自托管 PaaS 面板（Coolify / Dokploy，都是几万 star 的开源项目）比自己手搓 Docker 省事得多。
